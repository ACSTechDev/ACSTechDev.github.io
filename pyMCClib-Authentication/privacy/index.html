pyMCClib-Authentication

pyMCClib-Authentication is an open-source Python library providing authentication utilities for Microsoft and Minecraft services. It is designed for developers building applications that require Microsoft account authentication and access to Minecraft services.

This library is part of the pyMCClib project, an effort to professionally revive and modernize the original PyCraft ecosystem into a collection of modular, well-documented Python libraries for Minecraft development.

Project Organization

pyMCClib is being developed as a collection of independent Python modules under the pyMCClib GitHub organization. Each module focuses on a specific aspect of Minecraft development, allowing developers to install only the components they need.

pyMCClib-Authentication is responsible for Microsoft OAuth, Xbox Live authentication, Minecraft Services authentication, token management, and profile retrieval.

Project Status

pyMCClib is currently under active development. Documentation, examples, and source code will be published as development progresses and the libraries reach production readiness.

The authentication module is currently being validated against Microsoft's identity platform to ensure compatibility with modern authentication requirements.

Privacy

pyMCClib-Authentication does not operate any backend services and does not collect, store, or transmit user information on behalf of the project. Authentication requests are made directly between the client application and Microsoft's authentication services.

Applications using this library are responsible for securely storing any authentication tokens obtained during the sign-in process.

pyMCClib-Authentication does not provide or distribute a shared Microsoft Azure App Registration. Applications using this library must use their own Microsoft Azure App Registration and are responsible for complying with Microsoft's and Mojang's applicable terms of service.
